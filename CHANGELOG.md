# Changelog

## 0.1.0

First release: the engine, its command line, Python bindings, desktop workbench and WebAssembly demo. Before it, three rounds of fresh-context review of the numerics reported 77 groups of defects, each now a regression test in `crates/rashevsky/tests`. Three more cold reviews of the move to the bundled iCH360 model reported 50 findings, the last round none of high severity; each one that held up was fixed.
